# Ebana-Boutique-officiel
Ebana Boutique : Votre destination mode au cœur de Brazzaville et Sénégal



1. *Informations essentielles à propos de KongoLibs*

- *Nom du projet* : *KongoLibs*
- *But du site* : C’est une plateforme éducative et culturelle destinée aux étudiants de divers niveaux scolaires, allant de la 6e à la Terminale. L'objectif est de fournir des ressources, des examens, des devoirs, des tests, et d’autres outils pour les étudiants dans différents domaines académiques.
  
- *Cible* : 
  - *Élèves* (principalement de la 6e à la Terminale)
  - *Enseignants* (pour partager du contenu pédagogique)
  - *Parents* (pour suivre les progrès de leurs enfants)

- *Contenu principal* :
  - *Ressources scolaires* : Cours, exercices, vidéos, et tests
  - *Suivi de progression* : Suivi des notes et résultats d'examens
  - *Interaction communautaire* : Forums, blogs, discussions en ligne entre étudiants et enseignants
  
2. *Structure du site*

Voici la structure principale du site avec les sections qui doivent être incluses dans le *flowchart* :

1. *Page d'accueil* :
 - Introduction à KongoLibs
   - Accès direct aux différentes sections : Ressources, Examen, Test, Suivi
   - Liens vers les catégories : 6e à 3e, 2nde à Terminale

2. *Page Ressources* :
   - *Filtrage par classe* (6e, 5e, 4e, 3e, 2nde, 1ère, Terminale)
   - *Filtrage par matière* : Mathématiques, Français, Histoire, etc.
   - *Filtrage par type de contenu* : Cours, Exercices, Tests

3. *Page Tests et Examens* :
   - Interface pour *passer des tests en ligne*
   - *Historique des examens* passés
   - *Résultats en temps réel*

4. *Page Suivi* :
   - *Suivi des performances* des étudiants (par matière, par trimestre, par année)
   - Graphiques de progression
  
5. *Page Communauté* :
   - Forums de discussion
   - *Blogs* de révision et de partage d’informations
   - *Questions/Réponses* entre étudiants et enseignants

6. *Page Profil* :
   - Détails sur l'utilisateur
   - Abonnements
   - Notifications (résultats, nouveaux tests, mises à jour)

7. *Page Paiement/Abonnement* :
   - Options d’abonnement
   - Système de paiement en ligne

8. *Page FAQ / Aide* :
   - FAQ sur l’utilisation de KongoLibs
   - *Tutoriels vidéos* sur l’utilisation de la plateforme

3. *Design (Graphique et Esthétique)*

- *Couleurs dominantes* :
- *Bleu clair* : Représente la confiance, la fiabilité et la technologie. Utilisez des nuances de bleu pour les éléments importants, les boutons d’action et les en-têtes de sections.
   - *Orange ou Jaune* : Rappelle l’énergie et l’enthousiasme pour les jeunes. Utilisez-le pour attirer l'attention sur les sections importantes ou les appels à l'action (CTA) comme "S'inscrire", "Commencer le test", etc.
   - *Blanc ou Gris clair* : Pour le fond, afin de garder une interface claire et lisible.
   - *Vert* : Pour les messages positifs ou de progression (ex : bon résultat dans les tests, validation d’une action).
   - *Rouge* : Pour des erreurs, des messages d'avertissement (par exemple "Échec du test").

- *Police* : 
   - *Roboto ou Open Sans* : Utilisez une police sans-serif claire pour les titres et les textes.
   - *Merriweather* ou *Lora* : Pour les titres et l’accentuation, donnant un aspect plus formel.

4. *Flowchart Structure*

Voici la structure du flowchart que vous pouvez générer sur Figma :

1. *Utilisateur sur la page d'accueil* :
   - *Connexion* / *Inscription*
     - Si l'utilisateur est déjà inscrit → Accès au profil
     - Si l'utilisateur s'inscrit → Accès à un tableau de bord personnalisé
     
2. *Page Ressources* :
 - Sélection de la classe et de la matière
   - Affichage des ressources disponibles (cours, tests, exercices)
     - Accès aux ressources spécifiques
     
3. *Page Tests et Examen* :
   - Sélection du test/examen
   - Test en ligne
     - Soumettre les réponses
     - Calcul du score et résultat

4. *Page Suivi* :
   - Accéder au suivi de performance
   - Affichage des statistiques et graphiques de progression

5. *Page Profil* :
   - Mise à jour du profil
   - Consulter les historiques d'examen et résultats

6. *Page Abonnement* :
   - Choisir un abonnement (mensuel, annuel)
   - Système de paiement intégré (PayPal, Momo, Stripe)
     - Paiement accepté → Activation de l’abonnement

7. *Page Communauté* :
   - Accéder aux forums
   - Poser des questions ou répondre

5. *Wireframe Design*

Sur Figma, vous pouvez créer un wireframe en organisant les éléments suivants :

- *Page d'accueil* :
  - *En-tête* : Logo de KongoLibs, Menu de navigation
  - *Section centrale* : Description de la plateforme, options pour s'inscrire ou se connecter
  - *Sections secondaires* : Catégories d'examens, tests et ressources
  
- *Page Tests* :
  - *En-tête avec titre de test*
- *Questions et réponses* : Affichage de questions avec options de réponses sous forme de boutons radio ou cases à cocher
  - *Bouton* "Soumettre le test" avec affichage du résultat

- *Page Profil* :
  - *Détails de l'utilisateur* (nom, âge, école)
  - *Statistiques de progression* (graphique)
  - *Historique des tests* (tableau avec résultats passés)
  
- *Page Suivi de Performance* :
  - Graphiques de progression (par matière, par année)
  - Statistiques sur les résultats des examens
